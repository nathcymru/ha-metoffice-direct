# Community integration icon

Original cloud, sun and rain artwork, copyright (c) 2026 Nathan, MIT licensed.
This is the icon of this community integration. It is not an official Met Office
or Home Assistant logo and does not imply endorsement. `icon.svg` is the editable
source.

`icon.png` is 256 × 256 pixels and `icon@2x.png` is 512 × 512 pixels, matching the
[Home Assistant brand dimensions](https://contributors.home-assistant.io/core/integrations/brands/).
Both have transparent rounded corners. The filled icon works on light and dark
backgrounds, so the optional separate dark variant is unnecessary.

The PNGs were rendered with `@resvg/resvg-js` 2.6.2 using
`new Resvg(svg, { fitTo: { mode: "width", value: size } }).render().asPng()`.
This is a development tool only, with no additional runtime dependency.
